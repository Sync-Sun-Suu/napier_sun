## ✨ 5つのインタラクティブ・モード

| モード | 概要 | 操作方法 |
| :--- | :--- | :--- |
| **2.718 · 焚き火と対数螺旋時計** (`napier`) | ネイピア数の対数螺旋 $r(\theta) = a \cdot e^{b\theta}$ を核に、深層部から反重力で浮かび上がる火の粉が 1/f ゆらぎの風で揺らめくデスクトップ時計。焚き火のパチパチ音と毎分チャイムを搭載。 | クリック・ドラッグで火の粉と深層倍音が共鳴 |
| **01. 波紋と五音音階** (`ripples`) | 水面に広がる同心円波と、波同士の交点（干渉ノード）をリアルタイム計算。日本の陽音階チャイムが鳴ります。 | キャンバスをクリック／ドラッグ |
| **02. 振り子ハーモノグラフ** (`harmonograph`) | 2つの減衰振り子の周波数比（ネイピア共鳴 `2.72:1`、完全五度 `3:2`、準黄金比 `8:5` など）から緻密な幾何学曲線を描画。 | クリックで再描画・右パネルで比率変更 |
| **03. 万華鏡ドローイング** (`kaleidoscope`) | 座標変換行列でストロークを4〜16分割の回転対称＆鏡像反転し、光の幾何学模様を描きます。 | キャンバス上をドラッグして描画 |
| **04. 重力多体軌道** (`gravity`) | 逆二乗則 $F = G \cdot m / r^2$ に従う数百個の粒子の公転軌道をシミュレーション。 | クリックで引力源追加／Shift+クリックで斥力源追加 |
